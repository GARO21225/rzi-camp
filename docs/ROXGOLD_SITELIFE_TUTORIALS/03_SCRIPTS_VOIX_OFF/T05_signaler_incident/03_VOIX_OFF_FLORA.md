# T05 : script de voix off prêt pour FLORA

**Réglages de voix proposés** : voix française standard (pas d'accent marqué), timbre posé, débit **modéré (≈ 150 mots/min)**, ton professionnel et chaleureux. Générer **un fichier audio par plan** (P01 … P14) : c'est plus simple pour caler chaque phrase sur l'image dans HyperFrames.
Notation des pauses : `[pause 0,5 s]`. Les « … » indiquent un léger suspens.
Prononciation : « SiteLife » se dit *saït-laïf* ; « SLA » n'est jamais prononcé (on dit « délai de traitement »).
Le texte brut à coller dans FLORA, plan par plan, est dans `03_VOIX_OFF_FLORA.txt`.
